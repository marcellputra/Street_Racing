\## Deskripsi

Project game "STREET RACING" ini dikembangkan menggunakan Unity Engine sebagai pemenuhan tugas Ujian Tengah Semester (UTS).



Street Racing adalah game racing 3D bertema street racing modern yang menantang pemain untuk mengendarai mobil sport dan mencapai garis finish secepat mungkin di lintasan perkotaan modern.
